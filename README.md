# fresh-plugins

Plugins for the [Fresh](https://github.com/sinelaw/fresh) editor. Each directory is one package.

| Plugin | Description | Install (Package: Install from URL) |
|---|---|---|
| [git-sidebar](git-sidebar/) | Git section in the file-explorer sidebar: the branch, Staged Changes and Changes, kept current; stage, unstage, side-by-side diff | `https://github.com/deugene/fresh-plugins#git-sidebar`, or from a local checkout `/path/to/fresh-plugins#git-sidebar` |

Restart Fresh after installing.
